## Summary
Issue #287 at current main (5102783): the premise names files that never
existed in this repo (src/simulation/engineWorkerManager.ts; the test existed
only as a stale tsconfig exclusion) — same unpushed-workspace pattern as #293.
The direct-mode surface that DOES exist is engineWorker.ts's exported
processCommand/workerState/createSnapshot, and it was broken deeper than the
ticket describes: (1) the "not initialized" guard rejected `init` itself, so
the worker could never start under any path; (2) the second `onmessage`

commands); (3) error snapshots hardcoded isRunning:false/isPaused:true — the
exact state-hardcoding family the ticket targets, misreporting a running
worker as paused whenever a command failed.
