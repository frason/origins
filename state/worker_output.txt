## Checkpoint Payload Analysis
**Measured Size (realistic mid-game scenario):**
- Raw JSON: 4563.68 KB (4.457 MB) per checkpoint
- Estimated gzip (35%): 1597.29 KB (~1.56 MB) per checkpoint
- Breakdown: World grid 2181 KB | Phase 0 state 2182 KB

**Storage Backend: IndexedDB (confirmed)**
- localStorage: 5 MB limit → 1 uncompressed slot (insufficient)
- IndexedDB: 50 MB limit → 11 uncompressed slots, 32 gzip slots
- Planned 8-auto/2-manual (10 slots) requires ~45 MB raw, fits only via compression

**Versioned Checkpoint Format (prerequisite satisfied)**
- Already exists: `src/simulation/checkpointTimeline.ts` lines 9, 41, 87–91
  - `CHECKPOINT_FORMAT_VERSION = 1` constant
  - `SimulationCheckpoint.version: number` per-checkpoint field
  - `restoreCheckpoint()` mismatch check/throw for migrations
- Production code ready; no changes needed for Phase 1

**Compression: YES (gzip strongly recommended)**
Justification: 10 slots × 4.5 MB = 45 MB (hits 50 MB quota edge); gzip compression → ~15–16 MB provides safe margin.
