## Summary
Fixed false-negative in dispatcher.sh's worker-hallucination check by capturing the pre-run HEAD state before the worker invocation and including commits made during the worker run in the git_changes collection. The check now correctly recognizes files that were committed mid-run rather than treating them as uncommitted changes.

## Changes Made
- Added `pre_run_head=$(git rev-parse HEAD 2>/dev/null || true)` after output file reset (line 1106) to capture the git HEAD before the worker runs
- Extended git_changes collection (lines 1212-1219) to include `git diff --name-only "$pre_run_head" HEAD` results, guarded by a check for non-empty `$pre_run_head` to safely handle edge cases (e.g., first commit ever)
- The fix is additive: existing `git diff --name-only HEAD` and `git status --short` checks remain unchanged
- The three other hallucination branches (missing output file, missing manifest line) remain unmodified as required
