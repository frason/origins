Players should be able to introduce natural disasters into a running world — both beneficial (nutrient bloom, mild flood opening new wetland habitat, mineral-rich meteor seeding) and harmful (drought, cold snap, wildfire, toxic vent) — as a deliberate stewardship tool, distinct from the passive environmental pressures the simulation already generates.

For determinism, disasters should be seeded through the same RNG system as the rest of the engine so a replay reproduces the same event with the same outcome.

This is already comprehensively scoped as epic #125 (Scripted catastrophes and ecological recovery), which covers meteor/volcanic/earthquake/drought-flood/plague hooks, forecast/warning UI, and recovery-arc framework. Filing this issue to capture the specific beta ask (player-triggerable good and bad events, wired into the turning-point pause flow in the pause-at-key-moments issue) and to link it explicitly to that epic rather than duplicate its scope.
